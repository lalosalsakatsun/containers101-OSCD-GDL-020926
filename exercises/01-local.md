# Ejercicio 1 — Ejecutar la aplicación localmente

## Objetivo

Comprobar que la aplicación funciona antes de introducir Docker.

## Pasos

```bash
npm install
npm start
```

En el navegador ir a: http://localhost:3000

Después:

En el navegador ir a: http://localhost:3000/api/status

## Pregunta

¿Qué necesitas tener instalado para ejecutar esta aplicación?

Piensa en:

- Runtime
- Package manager
- Dependencias
- Código
- Configuración

## Resultado esperado

La aplicación muestra `Status: Running` y `/api/status` devuelve un JSON.
